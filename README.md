# TruckWay 🚛
גרסת PWA מחוברת ל-Supabase ול-Edge Function בשם truck-route.

## פריסה
1. העלה את כל הקבצים ל-GitHub.
2. ב-Vercel בחר Import Project.
3. Framework: Other.
4. Build Command: ריק.
5. Output Directory: .
6. Deploy.

## Supabase
יש להגדיר את secret בשם GRAPHHOPPER_API_KEY.
Edge Function: truck-route.
